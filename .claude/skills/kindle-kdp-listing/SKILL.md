# KDP登録情報の作成

## 出力: `kindle/books/<book-id>/KDP.md`
- タイトル / サブタイトル / シリーズ名
- 商品説明文(冒頭2行で悩みと約束。箇条書きで得られること。HTML可の範囲で)
- キーワード7個(検索されそうな語の組み合わせ)
- カテゴリ候補3つ(要:KDP画面で最終確認)
- 価格案とロイヤリティ(KDPの現行条件は公式ヘルプで確認してから書く)
- 表紙案: 2560×1600px(縦横比1.6:1)の推奨、文字の可読性(サムネイルで読めるか)、コンセプト3案

## 注意
- KDPの規約・ロイヤリティ率・サイズ要件は変更されるため、必ず公式ヘルプを確認し、確認日を記す。
- 他者の著作物・商標を表紙やタイトルに使わない。
