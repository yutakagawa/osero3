# Kindle市場リサーチ

目的: 「自分が書ける」×「読者がいる」×「競合に勝てる切り口がある」の交点を見つける。

## 手順
1. 著者の強み(経験・知識・文章の得意不得意)を確認する。不明なら質問する。
2. WebSearch で候補ジャンルごとに調べる: Amazon Kindleストアのカテゴリ、売れ筋の傾向、価格帯、レビューの不満点(=切り口の種)。
3. 候補を3〜5個に絞り、各候補を次の表で評価する(各1〜5点)。
   - 需要 / 競合の強さ(強いほど低点) / 自分の適性 / 継続してシリーズ化しやすいか / 執筆コスト
4. 上位2案について、競合上位5冊の「タイトル・価格・ページ数・レビューの不満」を整理する。
5. `kindle/docs/market-<YYYYMMDD>.md` に保存する。推奨案と理由を冒頭3行で書く。

## 注意
- 売上数値や順位は推測で書かない。確認できた事実と推定を分けて書く。
- 出典URLを必ず残す。
