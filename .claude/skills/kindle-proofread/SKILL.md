# 校正・推敲

## 手順
1. `python3 kindle/tools/check_manuscript.py <book>` を実行し、機械的な警告を拾う。
2. 章ごとに次の観点で読む: 誤字脱字 / 表記ゆれ(漢字・ひらがな・数字) / 長すぎる文 / 主語の欠落 / 論理の飛び / 重複 / 章の約束が回収されているか。
3. 直接直してよいのは誤字・表記ゆれのみ。文体や内容に関わる変更は、差分を示して著者の承認を得る。
4. 最後に `kindle/docs/proofread-<book-id>.md` に、直した点と判断を仰ぎたい点をまとめる。
