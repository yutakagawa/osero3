# 体験メモ → 章

## 前提
- 対象本の `PLAN.md` と `STYLE.md`、`IDEAS.md`(著者のメモ)を先に読む。
- 章の型: 〈型〉共通パターン → 〈現実〉著者の体験 → 〈使い方〉読者への1アクション → 〈注意〉うまくいかない条件。
- 文体は STYLE.md(砕けた・ツッコミ多め)。

## 手順
1. メモに書かれた**事実だけ**を使う。書かれていない日時・場所・人物・セリフ・感情は作らない。足りなければ、章末に「確認したいこと」として質問を並べる。
2. 事実を、〈現実〉の節に、著者の一人称で、時系列に並べる。笑いどころ(失敗、ズレ、ツッコミ)は誇張せずに強調する。
3. 〈型〉は、アニメ全般の傾向として書く。作品名は例示に最小限だけ。セリフの引用は短く、出所を示す。
4. 〈使い方〉は、読者が明日できる行動を1つに絞る。〈注意〉には現実と作品の違いを書く。
5. `chapters/` に `NN-slug.md` で保存し、`python3 kindle/tools/check_manuscript.py kindle/books/<book>` で確認する。
6. 家族・職場など特定されうる情報は、`docs/rights-checklist-anime.md` に沿って伏せる。

## 出力のルール
- 1章 1,500〜2,500字。
- 先頭は `# 章タイトル` の1行のみ。
- 事実が足りない箇所は、本文に `【要入力】` を残す(捏造で埋めない)。
