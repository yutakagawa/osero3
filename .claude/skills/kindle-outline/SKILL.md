# Kindle本の企画・構成

## 出力: `kindle/books/<book-id>/PLAN.md`
1. **ワンライン・コンセプト**: 「誰が」「何を得て」「どう変わるか」を1文で。
2. **ターゲット読者**: 1人の具体像(年齢層・悩み・検索しそうな語)。
3. **競合との差別化**: 3点以内。
4. **タイトル案**: メイン5案+サブタイトル。検索されやすい語を前半に置く。
5. **章立て**: 全体の文字数目標(実用書なら3〜5万字が目安)と、章ごとの目的・読後に読者ができること・目標文字数。
6. **特典・導線**: 次の本やメルマガなどへの導線(あれば)。

## 方針
- 1章1メッセージ。冒頭の「はじめに」で結論と得られるものを約束する。
- 章立て確定前に、必ず著者に確認をとる。
