# アニメを題材にした本の権利チェックリスト

> 一般的な注意点であり、法的助言ではありません。迷う箇所は、出版前に専門家(弁護士・出版社など)へ相談してください。

## 作品名・キャラクター名
- [ ] 作品名・キャラ名は、**例示として必要な範囲で**本文中にだけ使う
- [ ] **タイトル・サブタイトル・キーワード・商品説明の見出し**に作品名を入れない(誤認や、便乗に見えるのを避ける)
- [ ] 作品ロゴ・キャラ画像・公式画像・スクリーンショットは**使わない**(表紙にも本文にも)
- [ ] 公式を装う表現(「公式」「認定」など)や、作品の関連書籍に見える見せ方をしない

## セリフ・あらすじ・設定の扱い
- [ ] セリフの引用は、**短く**、本文が主・引用が従になる範囲に収め、**作品名など出所を明示**する
- [ ] あらすじの転載・長い要約は避け、自分の感想・体験の説明に必要な最小限にする
- [ ] ネタバレは、章頭に「※一部ネタバレあり」と明記する
- [ ] 歌詞は引用しない(別の権利管理があるため)

## 体験談の扱い
- [ ] 家族・友人・同僚・職場が特定される情報は書かない/仮名にする
- [ ] 他人の発言や出来事は、本人が特定されない形に
- [ ] 医療・メンタル・お金の話は、「個人の体験」と明記し、一般化しない

## 元ネタ(オマージュ元の書籍)
- [ ] 元の書籍の文章・章題・数字・言い回しは使わない
- [ ] 販売ページに、元の書籍名・著者名を載せない

## KDPの手続き
- [ ] 出版権・著作権は自分が保有している文章・画像のみ
- [ ] AI生成コンテンツの申告をKDPの現行ガイドラインに従って行う
