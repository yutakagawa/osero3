# Kindle出版チェックリスト

## 0. 事前準備(出版前に一度だけ)
- [ ] Amazonアカウントで KDP にサインイン、著者情報を登録
- [ ] 銀行口座(受取)と税務情報(米国との税務面談)を入力
- [ ] ペンネームを使う場合は、著者名の表記を決める
- [ ] 公式ヘルプ(コンテンツガイドライン・表紙要件)を一読

## 1. 企画
- [ ] ジャンル決定(`kindle-market-research`)
- [ ] PLAN.md 作成・承認(`kindle-outline`)
- [ ] STYLE.md(文体ガイド)作成

## 2. 執筆
- [ ] 全章ドラフト(`kindle-draft`)
- [ ] `check_manuscript.py` で警告ゼロに近づける
- [ ] 推敲・校正(`kindle-proofread`)
- [ ] `<!-- 要確認 -->` をすべて解消

## 3. 制作
- [ ] 表紙(縦2560×横1600px、JPEG)を `cover.jpg` として配置
- [ ] `build_epub.py` でEPUB生成
- [ ] Kindle Previewer などで表示確認(目次、改行、画像)

## 4. 登録・公開
- [ ] KDP.md の内容で商品情報を入力(`kindle-kdp-listing`)
- [ ] 価格・ロイヤリティ・KDPセレクトの可否を最終決定
- [ ] AI生成コンテンツの利用有無をKDP画面の指示どおり申告
- [ ] プレビュー確認後に公開(審査は通常数日以内)

## 5. 公開後
- [ ] レビュー・順位・読まれたページ数を週次で記録
- [ ] 2冊目の企画に反映
