# Kindle市場メモ(2026-10-04 時点・一次調査)

> 検索結果の要約です。数値は第三者サイトの記載を含み、**KDP画面・公式ヘルプで最終確認してください**。

## 結論(暫定)
ジャンルは未定。実績ベースで狙いやすい候補は次の3系統。いずれも「自分の経験を持ち込める切り口」があるかで決める。
1. AI活用・ChatGPT系の実用書(新興、競合も急増)
2. 副業・フリーランス・SNS運用系(安定需要、サブカテゴリ選びで順位が大きく変わる)
3. 生活密着系(健康・メンタル・暮らし。トレンドに左右されにくい)

## KDPの基本条件(日本)
| 項目 | 内容 | 出典 |
|---|---|---|
| 35%ロイヤリティ | 99円〜20,000円。他社でも販売可 | [電子書籍出版ラボ](https://publish-e-books.com/kdp-royalty-2pattern/) ほか |
| 70%ロイヤリティ | 250円〜1,650円(上限は2026年7月に改定との記載。**要公式確認**)。KDPセレクト登録(Amazon独占)が条件 | [Eresa](https://eresa-publishing.co.jp/column/kindle-royalty-70-35-price-strategy/) / [draftzero](https://draftzero.net/articles/kindle-pricing-strategy) |
| 配信コスト | 70%プランのみファイルサイズ1MBあたり約1円を控除 | 同上 |
| 表紙 | 縦2560×横1600px推奨、最小縦1000×横625px、JPEG/TIFF、比率1.6:1以上 | [KDP公式ヘルプ](https://kdp.amazon.co.jp/ja_JP/help/topic/G200645690) |

## ジャンル選定の傾向
- AI活用、SNS運用・X収益化、ショート動画運用が伸びているとの記載 → [解説記事](https://shuppan-lab.com/kindle-genre-urenaijump/)
- ビジネス・副業・自己啓発は常に需要がある安定市場 → [解説記事](https://kotonohasya.co.jp/kindle-genre-that-sells/)
- **サブカテゴリを絞ると順位が大きく変わる**(例: 副業本を「ビジネス・経済 > 起業・開業 > フリーランス」へ変更し3,000位台→100位以内との事例) → [解説記事](https://mamou.biz/kindle-publishing-category/)
- カテゴリ別の登録冊数と参入難易度の一覧 → [note記事](https://note.com/yamanasi_takasi/n/n413d204879cc)
- 公式ランキング(実際の売れ筋は自分の目で確認する) → [Amazon売れ筋](https://www.amazon.co.jp/gp/bestsellers/digital-text/2275256051)
